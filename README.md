# SQ-DiT: Slider Quant for Diffusion Models

This repository applies the **SliderQuant** quantization methodology to **Diffusion Transformers (DiT)**, along with evaluation tools for the quantized models.

The approach adapts SliderQuant to incorporate the timesteps used in DiT, optimizing the **Mean Squared Error (MSE)** across all timesteps simultaneously for *ImageNet-1K class-conditional models*.


## Installation

1. **Install PyTorch:** Since this project relies on GPU acceleration, you need to install `torch` and `torchvision` according to your specific CUDA version.

2. **Install other dependencies:** Install the rest of the required libraries using the provided `requirements.txt` file using:
    ```bash
    pip install -r requirements.txt
    ```

## Quantization

The quantization process is performed using `quantizer.py`. It takes a pre-trained DiT model and quantizes it based on a YAML configuration file.

### How to run
You can run the quantizer via the command line:
```bash
python quantizer.py -m <model_id> -c <path_to_config.yaml>
```


**Arguments:**
- `-m, --model_id`: HuggingFace Model ID
- `-c, --config`: Path to the YAML configuration file (default is `yaml/default.yaml`).


The quantized model will be saved in the `output` directory with the following structure `<model_id>-W<bits_low>A<bits_act>` and the runtime statistics (VRAM, time) will be saved in a file with the same name inside the `json` directory.

## Evaluation Process

The evaluation of a quantized model consists of comparing images generated from the model to an existent dataset using the following metrics:
1. **FID** (Frechet Inception Distance)
2. **IS** (Inception Score)
3. **sFID** (Spatial FID)
4. **CMMD** (CLIP Maximum Mean Discrepancy)
5. **Generation values** (Peak VRAM usage and average generation time)


### Image Generation
Use `script/gen_fid_images.py` to generate the images required for metrics calculation. The images generated must be at least one for each class (1000 classes), but the recommended number is al least 10 images per class.

```bash
python script/gen_fid_images.py -m <model_id> -n <images_per_class> -bs <batch_size> -s <seed> -i <inference_step>
```

**Arguments:**
- `-m, --model_id`: Model ID. It will look for the quantized model in the `output/<model_id>` folder, or search for a non quantized one if not found.
- `-n, --images_per_class`: Number of images to generate per class (default: 10).
- `-bs, --batch_size`: Batch size for generation (default: 1).
- `-s, --seed`: Seed for generation (default: 42).
- `-i, --inference_step`: Inference step for non-quantized models (default: 20).

The generated images will be saved in the `FID_images/<model_id>` directory. Information about the generation (VRAM, batch size) will be saved in `json/<model_id>.json`.

### Metrics Calculation
Use `script/calculate_metrics.py` to calculate the evaluation metrics between the generated images and the ImageNet validation dataset (automatically downloaded).

```bash
python script/calculate_metrics.py -m <model_id> -pd <path_dataset> -pg <path_generated> -bs <batch_size> -n <images_per_class> -i <inference_step> --download
```

**Arguments:**
- `-m, --model_id`: Model ID.
- `-pd, --path_dataset`: Path to the real dataset (ImageNet validation dataset). If using `--download`, this is where the dataset will be saved.
- `-pg, --path_generated`: Path to the generated images (images generated by `script/gen_fid_images.py`).
- `-d, --download`: Flag to automatically download the required ImageNet validation images to `-pd` using the HuggingFace datasets library.

    > ℹ️ You must have `HF_TOKEN` configured in a `.env` file to download from HuggingFace.

- `-bs, --batch_size`: Batch size for metrics calculation (default: 1).
- `-n, --images_per_class`: Number of images per class (must be the same as `script/gen_fid_images.py`) (default: 10).
- `-i, --inference_step`: Inference step for non-quantized models (default: 20).

The calculated metrics will be saved in `json/<model_id>.json`.

## Single Image Generation (Inference)

You can generate images using `script/inference.py`. This script supports generating images from both the quantized model and the original unquantized model for comparison.

### How to run
- Generate an image using the **quantized model**:
    ```bash
    python script/inference.py -d output/<quantized_model_dir> -c <class_label> -s <seed>
    ```

- Generate an image using the **original model**:
    ```bash
    python script/inference.py -m <model_id> -i <inference_steps> -c <class_label> -s <seed>
    ```


**Arguments:**
- `-d, --quant_dir`: Path to the quantized model directory.
- `-m, --model_id`: HuggingFace model ID for the original model.
- `-i, --inference_steps`: Number of inference steps (default: 20).
- `-c, --class_label`: Class label to generate (default: 19 ➝ chickadee).
- `-s, --seed`: Random seed for reproducibility (default: 42).

The generated images will be saved in the root folder as `quantized_image_seed_<seed>.png` or `original_image_seed_<seed>.png` depending on the model used.
